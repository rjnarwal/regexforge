**RegexForge** is a real-time regular expression development studio featuring live synchronized highlight overlays, capture group inspection, plain-English syntax tree explanation, string substitution studio, and multi-language code export.

---

## ✨ Features

- 🌈 **Live Multi-Color Highlight Overlay**: Real-time matching against test strings with distinct colors for each match index and capture group.
- 🧩 **Capture Groups Inspector**: Breakdown of numbered groups (`Group 1`, `Group 2`) and named groups (`$<name>`) with character offsets and 1-click copy.
- 📖 **Plain-English Syntax Explainer**: Human-readable explanations of anchors (`^`, `$`), character classes (`\d`, `\w`), quantifiers (`+`, `*`, `{2,5}`), and lookarounds (`(?=...)`, `(?!...)`).
- 🔄 **Substitution / Replace Studio**: Test string transformations with dynamic group placeholders (`$1`, `$2`, `$&`) and live diff metrics.
- 💻 **Multi-Language Code Generator**: Export production snippets for Kotlin (Android), Java, TypeScript, Python, Go, and Rust.
